Built and deployed a full-stack hospitality management platform for a live hostel in Canggu, Bali — Node.js 20 + Express REST API, SQLite persistence, JWT authentication, Helmet security stack, rate limiting, and HTTPS enforcement via Nginx + Certbot on DigitalOcean.

Integrated OCR-based passport scanning with MRZ parsing for automated guest check-in, eliminating manual ID data entry. Built CSV ingestion, XLSX report generation, and file upload workflows unifying booking, payment, and guest data pipelines. Delivered as a PWA with a Tailwind frontend and a Playwright end-to-end test suite.

Containerized with Docker and Docker Compose; deployed to an Ubuntu 24.04 droplet with systemd service management for reliable uptime.

*Codebase is private — built for a paying client as part of an ongoing freelance engagement.*
